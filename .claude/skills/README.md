# Скилы проекта

Подключённые руководства для Claude Code. Это чужой текст без исполняемого
кода: он влияет только на то, как агент принимает решения по интерфейсу.

| Каталог | Откуда | Лицензия |
|---|---|---|
| `frontend-design/` | [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | Apache 2.0 |
| `redesign-existing-projects/` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill/tree/main/skills/redesign-skill) | MIT |

`frontend-design` заставляет сначала собрать систему токенов и защищает от
дефолтного «сгенерированного» вида. `redesign-existing-projects` — чек-лист
аудита уже существующего интерфейса: типографика, цвет, слои, состояния.

Обновляются копированием из исходных репозиториев. Правки в них не вносим:
иначе следующее обновление затрёт их молча.
